01로그인과 기본 화면

관리자 페이지에 들어가는 첫 단계입니다.

접속과 로그인

주소창에 petbro-website.hsweb.pics/admin 을 입력하면 비밀번호 입력 화면이 나타납니다. 비밀번호를 입력하고 로그인 버튼을 누르면 상품 목록 화면으로 바로 이동합니다.

Note

로그인 상태는 8시간 유지됩니다. 시간이 지나면 다시 로그인 화면으로 돌아오지만, 작업 도중 자동으로 로그아웃되지는 않으니 안심하셔도 됩니다.

화면 구성

상단 바 왼쪽에 PAT BRO 로고가 있고, 오른쪽 끝에는 사이트 보기 · 로그아웃 버튼이 있습니다. 가운데 메뉴는 두 개입니다.

메뉴 역할
상품 판매 중인 상품을 추가·수정·삭제하고, 노출 여부를 조정합니다.
주문 고객 주문 내역을 확인하고 배송 상태와 송장 번호를 관리합니다.

오른쪽의 사이트 보기 버튼을 누르면 실제 고객이 보는 화면이 새 창으로 열립니다. 변경 내용을 즉시 확인할 때 유용합니다.

02상품 관리

쇼핑몰에 노출되는 상품 정보를 다루는 가장 자주 들어오는 화면입니다.

상품 목록 한눈에 보기

좌측 메뉴에서 상품 을 누르면 등록된 모든 상품이 표 형태로 정리되어 있습니다. 각 행이 하나의 상품에 해당합니다.

컬럼 내용
이미지 대표 이미지 썸네일.
상품명 · slug 상품 이름과 고객 페이지 URL에 들어가는 영문 식별자.
가격 · 재고 현재 판매가와 남은 재고. 재고가 0이면 빨간색으로 표시됩니다.
상태 활성 은 사이트에 노출, 임시저장 은 비공개. 버튼을 누르면 즉시 전환됩니다.
작업 각 상품을 수정하거나 삭제하는 버튼.

새 상품 추가하기

  1. 상품 목록 우측 상단의 ＋ 새 상품 추가 버튼을 누릅니다.
  2. 상품명, URL slug(영문 소문자·숫자·하이픈), 영문 라벨, 규격, 상세 설명을 채웁니다. ＊ 표시 항목은 필수 입니다.
  3. 가격(원 단위 정수)·재고·진열 순서를 입력합니다. 진열 순서는 작은 숫자가 위에 나오고, 같은 번호여도 큰 문제는 없습니다.
  4. 이미지 카드 두 곳에 사진을 올립니다. 사용법은 03 이미지 업로드 에서 자세히 다룹니다.
  5. 태그 입력칸에 태그를 적고 추가 버튼 또는 Enter 로 등록합니다. 태그는 쇼핑 그리드 카드에서 작게 노출되는 라벨입니다.
  6. 우측 상단 상품 추가 버튼을 누르면 즉시 저장되고 목록으로 돌아갑니다.
Tip · slug

slug는 한 번 정하면 가급적 바꾸지 않는 편이 좋습니다. 외부에 공유된 링크가 끊어질 수 있어서, 새 상품으로 교체하거나 시즌이 끝난 상품을 비공개로 돌릴 때는 slug를 그대로 두고 상태만 임시저장 으로 바꿔주세요.

상품 수정과 삭제

목록의 수정 버튼을 누르면 추가할 때와 동일한 폼이 열리고, 기존 값이 그대로 채워져 있습니다. 필요한 부분만 바꾸고 변경사항 저장 을 누르면 적용됩니다.

삭제 는 되돌릴 수 없습니다. 확인 창이 한 번 뜨고 거기서 한 번 더 눌러야 실제로 지워집니다. 잠깐 노출만 멈추는 거라면 삭제 대신 상태를 임시저장 으로 바꿔두는 편을 권합니다.

상태 빠르게 전환하기

상태 버튼을 누르면 활성 ↔ 임시저장 이 즉시 전환됩니다. 행사 시작·종료 시점에 빠르게 노출 여부를 조정할 때 가장 유용합니다.

상태 고객 화면 노출 주문 가능 여부
활성 ○ 노출됨 ○ 가능
임시저장 × 비공개 × 차단
보관 × 비공개 × 차단 · 정리용

03이미지 업로드

상품 화면에서 사용하는 이미지는 두 종류입니다. 두 영역은 서로 다른 곳에 노출되므로 헷갈리지 않게 구분해서 올립니다.

구분 노출되는 위치 권장 형태
대표 이미지 상품 목록 카드의 정사각 썸네일과, 상세 페이지 상단 갤러리 영역에 표시됩니다. 첫 번째 이미지가 대표가 됩니다. 정사각·1200×1200px 정도
상세페이지 이미지 상세 페이지 가운데에 위에서 아래로 스크롤되며 길게 표시되는 마케팅 이미지입니다. 가로 860–1200px · 세로 자유

업로드하는 방법

  1. 업로드 영역(점선 박스)에 파일을 끌어다 놓거나 박스를 한 번 눌러 파일 선택창을 엽니다.
  2. 한 번에 여러 장을 같이 선택해도 됩니다. 업로드는 자동으로 시작되며 진행 중에는 박스가 흐려집니다.
  3. 업로드가 끝나면 아래에 미리보기가 나타납니다. 마우스를 올리면 삭제 또는 순서 조정 버튼이 보입니다.
파일 규칙

허용 형식은 JPG · PNG · WebP · GIF 이며 한 장 최대 5MB, 한 번에 최대 10장 까지 올릴 수 있습니다. 그 이상이면 두 번에 나누어 올려주세요.

대표 이미지 정리

대표 이미지는 그리드 형태로 표시됩니다. 첫 번째 칸에 있는 이미지가 실제 썸네일·갤러리 첫 화면에 사용됩니다. 다른 이미지를 첫 번째로 올리고 싶다면 마우스를 올렸을 때 나타나는 대표 지정 버튼을 누르면 그 자리로 이동합니다.

상세페이지 이미지 순서 바꾸기

상세페이지 이미지는 위·아래로 길게 쌓이는 형태입니다. 마우스를 올리면 오른쪽에 화살표 두 개와 ✕ 버튼이 나옵니다. 화살표로 위·아래 위치를 조정할 수 있고, 왼쪽 위에 표시되는 01 · 02 번호로 현재 순서를 한눈에 볼 수 있습니다.

자주 하는 실수

상세페이지 이미지를 대표 이미지 칸에 잘못 올리면, 썸네일이 너무 길게 잘려서 어색하게 보입니다. 두 영역의 라벨을 한 번 더 확인하고 올려주세요.

04주문 관리

고객 주문이 들어오면 이 화면에서 결제·배송 상태를 확인하고 송장 번호를 입력합니다.

한눈에 보는 요약

주문 화면 상단에는 카드 세 개가 있어 운영 현황을 빠르게 확인할 수 있습니다.

카드 내용
전체 주문 지금까지 접수된 모든 주문 건수.
결제 완료 고객이 결제까지 마친 주문 건수.
누적 매출 결제 완료 주문의 합계 금액.

결제 상태와 배송 상태 구분하기

각 주문에는 두 가지 상태가 함께 붙습니다.

결제 상태
상태 의미
결제 대기 주문은 들어왔으나 결제가 완료되지 않음. 보통 결제창 이탈.
결제 완료 고객이 결제를 마침. 출고 준비를 시작하면 됩니다.
결제 실패 한도 초과·카드 거부 등으로 결제가 거절됨.
결제 취소 · 환불 결제 후 취소·환불 처리가 완료됨.
배송 상태
상태 이럴 때 사용합니다
주문 접수 결제는 완료되었으나 아직 출고 준비 전.
준비 중 포장·라벨링 작업 중.
배송 중 택배사에 인도 완료. 송장 번호 입력 시점.
배송 완료 고객 인수 확인됨.
주문 취소 운영 측 사유로 취소 처리.

배송 처리하기

  1. 결제 완료 표시가 붙은 주문을 찾습니다. 시간이 지난 주문일수록 위에서 아래로 정렬되어 있습니다.
  2. 오른쪽 배송 처리 카드에서 적절한 상태를 선택합니다. 포장 시작 시점에는 준비 중, 택배 발송 시점에는 배송 중 으로 변경합니다.
  3. 송장 번호가 발급되면 그 자리에서 입력하고 저장 을 누릅니다. 입력 후에도 언제든 다시 수정할 수 있습니다.
Note

상품 출고가 완료되면 재고는 결제 완료 시점에 이미 자동 차감되어 있습니다. 별도로 재고를 줄이는 작업은 필요하지 않습니다.

05자주 묻는 질문

상황 대응
로그인 화면에서 비밀번호가 틀렸다고 나옵니다. 운영 시점에 비밀번호를 변경했다면 그 비밀번호를 사용해야 합니다. 초기값(1234)은 보안상 변경되어 있을 가능성이 높습니다.
상품을 저장하려는데 slug 오류가 뜹니다. 영문 소문자·숫자·하이픈 외 다른 문자가 포함되어 있는지 확인합니다. 한글, 공백, 기호는 사용할 수 없습니다.
사진을 올렸는데 미리보기가 보이지 않습니다. 한 장이 5MB를 넘었거나 허용 형식이 아닌 경우입니다. 업로드 영역 아래에 빨간색 안내가 함께 표시됩니다.
실수로 상품을 삭제했습니다. 삭제는 되돌릴 수 없습니다. 동일한 정보로 다시 등록해야 합니다. 삭제 전에 한 번 더 점검하는 습관을 들이는 게 가장 안전합니다.
결제 완료된 주문을 취소하고 싶습니다. 사이트의 결제 취소 기능은 자동화되어 있지 않습니다. 토스페이먼츠 관리자 콘솔에서 결제를 취소한 뒤, 이 화면의 결제 상태를 결제 취소 로 변경합니다.
상세 이미지가 너무 길어 한 번에 안 올라갑니다. 상하로 두 장 이상으로 나누어 업로드하면 됩니다. 어드민에서 화살표 버튼으로 순서를 자유롭게 조정할 수 있어, 합쳐서 보일 때 자연스러운 연결이 가능합니다.

한 가지만 기억한다면

상품 정보를 잠시 가리고 싶을 때는 삭제 가 아니라 임시저장. 이 한 가지만 지켜도 운영 중에 일어나는 실수의 절반은 막을 수 있습니다.
